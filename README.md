# Odin Landing Page

A static landing page built as part of **The Odin Project** Foundations curriculum. The goal of this assignment was to recreate a given design from scratch using only HTML and CSS, with a strong focus on **Flexbox** for layout.

## Live Demo

[https://marktwin25.github.io/Odin-Landing-Page/](https://marktwin25.github.io/Odin-Landing-Page/)

## About the Project

This is one of the early projects in The Odin Project. It puts into practice the basics of semantic HTML, CSS styling, and Flexbox-based positioning. The page follows the structure specified in the assignment: a header with navigation, a hero section, a features/information section, a quote block, a call-to-action banner, and a footer[reference:0].

## Built With

- **HTML5** – semantic structure.
- **CSS3** – styling and layout.
- **Flexbox** – used throughout for aligning and distributing elements[reference:1].
